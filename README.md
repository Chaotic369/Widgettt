# TextWidget Studio (Android Home Screen Widget App)
An Android Home Screen Text Widget application built with Kotlin and custom Canvas bitmap rendering so you can bypass standard RemoteViews limitations.
## Features
 * **Freeform Shape Sculpting**: Choose between Rectangle, Rounded, Pill Capsule, Circle/Oval, Superellipse (Squircle), Polygon (3 to 12 sides), Cyber Cut Corners, and Starburst badges.
 * **Full Background Transparency & Gradients**: Adjust alpha opacity from 0 (completely invisible background) to 255 (solid), with optional dual-tone angled gradients and customizable border strokes.
 * **Typography & Font Engine**: Customize font family, font size (10sp to 72sp), bold/italic styles, letter spacing, line spacing, and drop shadow glow.
 * **Interactive Placement & Rotation**: Drag text directly on the live preview canvas or fine-tune X/Y percentage offsets, text alignment, inner padding, and 360° rotation.
 * **Dynamic Home Screen Resizing**: Automatically re-renders crisp vector-like bitmaps whenever you resize the widget on your Android launcher.
